# QLens 产品概述

> **QLens 是一个看图工具，更重要的是，它提供了一套为 AI 时代思考设计的通用图片标签协议。**

## 为什么会有 QLens？

### 起点一：找不到一个"像 Picasa 那样"的看图器

用过 Picasa 的人都知道那种体验：**轻、快、干净**，双击打开就能看，界面不打扰，浏览效果赏心悦目。但 Picasa 早已停止维护。今天的替代品呢？

- **ACDSee 之类**：功能全但太重，启动慢、界面堆满工具栏
- **其他看图器**：要么够轻但浏览效果差，要么效果还行但根本谈不上轻

QLens 的起点，就是想找回 Picasa 那种"轻快干净的看图体验"。

### 起点二：看图工具都缺一样东西

每个人电脑里都有一堆照片——婚礼的、旅行的、随手拍的、工作素材的。市面上的看图工具能把图打开、缩放、翻页，做得又快又漂亮，但**没有一样东西能回答**：

> "我去年在海边拍的那 200 张照片里，哪些是闭眼的？"

## QLens 的三件套

QLens 由三个组件组成，围绕一套开放的图片标签协议（`qltag.db`）构建：

```
┌─────────────────────────────────────────────────────────┐
│                  QLens 标签协议 (qltag.db)               │
│  每文件夹一个 SQLite DB —— 任何软件/AGENT 可读写          │
└───────────┬──────────────────────────┬──────────────────┘
            │                          │
   ┌────────▼────────┐       ┌─────────▼─────────┐
   │  QLens Manager  │       │ QLens QuickView   │
   │  (Qt 文件管理器) │       │ (原生 Win32+D3D11) │
   │  缩略图/标签/QC  │       │ 极速看图 + HDR     │
   └────────┬────────┘       └─────────┬─────────┘
            │                          │
   ┌────────▼──────────────────────────▼─────────┐
   │            QLens MCP Server                  │
   │  把图片库开放给 AI 客户端（Claude/Cursor…）   │
   └──────────────────────────────────────────────┘
```

### 1. QLens Manager —— 标签管理 + 文件管理

Qt 写的文件管理器风格界面，是 QLens 的"工作台"：

- **缩略图网格**：异步加载、文件夹拼图预览、格式图标、Ctrl+滚轮缩放
- **标签系统**：右侧面板打标（带补全）、标签颜色、批量加/删标签、**组合筛选**（多标签 AND）、固定标 QC 筛选
- **QC 质检**：一键批量检测当前文件夹（曝光过度/模糊/色偏），结果以 emoji 角标标在缩略图上
- **批量操作**：转换格式、调整大小、重命名（ACDSee 风格）
- **内置查看器**：双击进大图，缩放/旋转/翻页

### 2. QLens QuickView —— 极速看图器

原生 Win32 + D3D11，无 Qt 依赖，**目标是启动快、内存低、看图顺**：

- 启动即看，滚轮翻页，F/S 一键 100%/适配
- **HDR 渲染**：真 HDR 图（16bit+）物理直通，SDR 图在 HDR 屏上增强显示
- **WIC 全格式** + 解码插件（HEIC/AVIF/SVG 已实现，可扩展新格式）
- 底部缩略图导航条、拖入即看、GIF 动画、EXIF 自动旋转

### 3. QLens MCP Server —— AI 生态

把图片库通过 MCP（Model Context Protocol）开放给外部 AI 客户端：

- 搜索/组合搜索/统计/打标/移动/批量分析 等 14 个工具
- AI 通过它读库、打标、做 QC 分析——**QLens 本身零 AI 代码**
- 分析前自动预压缩超大图，防止烧爆 token

## 核心：标签协议

一切围绕 `qltag.db`——每个文件夹一个 SQLite 数据库，纯文件名存取，树状天然。

**分类哲学**：标签按检测方式分类——

- **固定标（qc）**：非 AI 能靠谱检测的（曝光过度/模糊/色偏）——本地 CV
- **标准标（ai）**：必须 AI 检测的（红眼/闭眼）——MCP/外部 AGENT
- **普通标签**：手动或任意

详见 [标签协议规范](QLENS_TAG_PROTOCOL.md)。

## 使用流程（典型）

1. 用 QuickView 看图（极速、HDR）
2. 双击进 Manager（或手动打开）——浏览文件夹、双击进大图
3. 选中图打标签（右侧面板 / 批量）
4. 点「QC 检测」批量打固定标
5. 用组合筛选 / QC 筛选找出需要的图
6. （可选）让 AI 通过 MCP 读库、补标准标、做深度分析
