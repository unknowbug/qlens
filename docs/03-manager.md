# QLens Manager 手册

Qt 文件管理器风格——浏览文件夹、管理标签、QC 质检、批量操作。

## 启动与界面

- 启动默认打开系统图片文件夹（`%USERPROFILE%\Pictures`，跟随系统注册位置）。
- 命令行参数传入图片路径 → 打开所在文件夹并选中该图。

```
┌────────────────────────────────────────────────────────────┐
│ 菜单栏：文件 设置 MCP 帮助                                    │
│ 工具栏：← → ↑ [路径面包屑] [筛选:▾][QC:▾][高亮:▾][✕][QC 检测] │
├──────────┬─────────────────────────────────┬───────────────┤
│ 浏览树    │  缩略图网格                      │  标签面板      │
│ (文件夹)  │  （双击进查看器 / 右键菜单）      │  (打标/颜色)   │
├──────────┴─────────────────────────────────┴───────────────┤
│ 状态栏：图片总数 / 选中数 / 选中文件大小                      │
└────────────────────────────────────────────────────────────┘
```

## 工具栏

| 控件 | 功能 |
|---|---|
| `←` `→` `↑` | 历史后退 / 前进 / 上级目录 |
| 路径面包屑 | 点段跳转；点 `\` 分隔符弹子文件夹下拉；点空白进入路径编辑（Esc 退出） |
| 筛选 ▾ | 按标签过滤（可编辑输入）；**逗号 = 多标签 AND**（如 `猫, 白`） |
| QC ▾ | 固定标筛选（category='qc'），与标签筛选叠加 |
| 高亮 ▾ | 按标签给网格项加颜色标记 |
| `✕` | 清除过滤与高亮（QC 回"全部"） |
| `QC 检测` | 批量检测当前文件夹（曝光过度/模糊/色偏）并写固定标 |

## 右键菜单（缩略图网格）

| 菜单项 | 功能 |
|---|---|
| 在查看器中打开 | 进大图 |
| 另存为... | PNG/JPEG/WebP/BMP |
| 复制 | **三合一**：文件 + 路径文本 + 图片位图 |
| 重命名 (F2) | 内联 / 批量 |
| 删除（回收站） | `QFile::moveToTrash` |
| 批量转换格式... | 选格式 + 输出目录，全文件夹转换 |
| 批量调整大小... | 最长边像素 + 输出目录（不覆盖原图） |
| 批量重命名... | 名称模板 + 起始序号（ACDSee 风格） |
| 批量添加标签... | 逗号分隔，作用于选中集 + 右键项 |
| 批量移除标签... | 逗号分隔 |

**拖放**：拖出网格 = 复制文件到资源管理器；拖入 = 同盘移动 / 跨盘复制（文件夹递归）。

## 标签系统

- **右侧标签面板**：显示选中图已打标签；输入框 `标签1, 标签2` + 回车批量打标；输入时实时补全候选，`Tab` 补全首个。
- **标签颜色**：标签项右键「设置颜色」弹取色器，色点显示在标签前（协议 `tags.color`）。
- **组合筛选**：筛选框逗号分隔多标签 = **AND**；过滤时隐藏文件夹。
- **QC 筛选**：只看命中了某个固定标的图（如"模糊"）。
- 打标/删标后，筛选候选与缩略图角标自动刷新。

## QC 检测（固定标）

「QC 检测」按钮对当前文件夹**后台批量**检测（不卡 UI），结果写入固定标：

| 固定标 | 算法 |
|---|---|
| 曝光过度 ☀ | 亮度 >229 像素占比 >15% |
| 色偏 🎨 | RGB 通道均值最大偏差 >20 |
| 模糊 🌫 | 灰度 3×3 拉普拉斯方差 <60 |

命中固定标的缩略图**右上角叠加 emoji 角标**。完成状态栏显示统计（过曝 N | 模糊 M | 色偏 K）。

> 分类哲学：固定标（qc）= 本地 CV 可检测；标准标（ai）= 必须 AI 检测（红眼/闭眼，走 MCP）。详见[标签协议](QLENS_TAG_PROTOCOL.md)。

## 内置查看器

- 双击图片进入；顶部 `← 返回` 按钮 + 完整路径；双击查看器返回网格。
- 支持 QImageReader 全格式 + `cr2 cr3 nef arw dng rw2 heic heif avif svg svgz jxr`（qlens 回退）。
- 原图小于窗口时显示 100% 不放大；>4096px 预缩放解码。
- 状态栏显示文件名 / 尺寸 / 格式 / 大小；切图时右侧标签面板跟随。

显示：图片总数 / 当前选中几张 / 当前选中文件大小。
